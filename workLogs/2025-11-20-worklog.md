### Details
템플릿 타입별 아이콘을 표시하는 재사용 가능한 `TemplateIcon` 컴포넌트를 구현하고, 관련 페이지에 적용했습니다.

#### Component Structure
```tsx
interface TemplateIconProps {
  type: string;
  size?: number;
  className?: string;
}

export function TemplateIcon({ type, size = 20, className = "" }: TemplateIconProps)
```

#### Icon Mappings
- `sermon` → Book (설교)
- `prayer` → Heart (기도)
- `meditation` → Sparkles (묵상)
- default → FileText (기타)

#### Applied Pages
1. **Templates Page**: 템플릿 목록에 아이콘 추가
2. **New Note Page**: 템플릿 선택 UI에 아이콘 추가
3. **Home Page**: 템플릿 카드에 아이콘 추가

### Rationale
- **시각적 개선**: 템플릿 타입을 한눈에 식별 가능
- **재사용성**: 단일 컴포넌트로 일관된 아이콘 표시
- **확장성**: 새로운 템플릿 타입 추가 시 아이콘만 매핑하면 됨
- **타입 안전성**: TypeScript로 props 타입 정의

- **Runtime**: Edge runtime for optimal performance
- **Format**: PNG (32x32)

- **Color**: Blue-600 (#2563EB) background with white icon


### Rationale
- **브랜딩**: 시냇가(Shinatga) 앱의 시각적 정체성 확립
- **사용자 경험**: 브라우저 탭과 북마크에서 쉽게 식별 가능
- **최적화**: Edge runtime으로 빠른 생성 및 전송

  - [apps/web/app/api/templates/[id]/route.ts](apps/web/app/api/templates/[id]/route.ts)
- **Type**: Security enhancement, User authentication

### Details
Google OAuth 인증을 기반으로 노트와 템플릿에 사용자 소유권을 구현했습니다. 이제 각 사용자는 자신의 데이터만 조회/수정/삭제할 수 있습니다.

#### Notes API Changes

**GET /api/notes**
- ✅ 인증 필수: `auth()` 함수로 세션 확인
- ✅ 본인 노트만 조회: `where.userId = session.user.id`
- ✅ 미인증 시 401 에러 반환

**POST /api/notes**
- ✅ 인증 필수: 로그인 사용자만 노트 생성 가능
- ✅ 실제 사용자 ID 사용: `userId: session.user.id`
- ❌ 테스트 유저 생성 로직 제거

**GET /api/notes/[id]**
- ✅ 소유권 검증: `where.id AND where.userId` 조건
- ✅ 타인 노트 접근 불가: 404 에러 반환

**PATCH /api/notes/[id]**
- ✅ 본인 소유 노트만 수정 가능
- ✅ 소유권 확인 후 수정 진행

**DELETE /api/notes/[id]**
- ✅ 본인 소유 노트만 삭제 가능
- ✅ 소유권 확인 후 삭제 진행

#### Templates API Changes

**GET /api/templates**
- ✅ 기본 템플릿 + 본인 템플릿만 조회
- ✅ `OR` 조건: `isDefault: true` 또는 `userId: session.user.id`
- ❌ 공개 템플릿 로직 제거 (isPublic)

**POST /api/templates**
- ✅ 인증 필수: 로그인 사용자만 템플릿 생성 가능
- ✅ 실제 사용자 ID 사용: `userId: session.user.id`
- ❌ 테스트 유저 로직 제거

**GET /api/templates/[id]**
- ✅ 기본 템플릿 또는 본인 템플릿만 조회
- ✅ `findFirst` with `OR` 조건 사용

**PATCH /api/templates/[id]**
- ✅ 본인 소유 템플릿만 수정 가능
- ✅ 기본 템플릿 수정 불가 (403 에러)

**DELETE /api/templates/[id]**
- ✅ 본인 소유 템플릿만 삭제 가능
- ✅ 기본 템플릿 삭제 불가 (403 에러)

### Security Improvements

#### Authentication
```typescript
const session = await auth();

if (!session?.user?.id) {
  return NextResponse.json(
    { error: "로그인이 필요합니다." },
    { status: 401 }
  );
}
```

#### Ownership Verification (Notes)
```typescript
const note = await prisma.note.findUnique({
  where: {
    id,
    userId: session.user.id,  // 본인 소유만
  },
});
```

#### Ownership Verification (Templates)
```typescript
const template = await prisma.template.findFirst({
  where: {
    id,
    OR: [
      { isDefault: true },      // 기본 템플릿
      { userId: session.user.id },  // 본인 템플릿
    ],
  },
});
```

### Rationale
- **보안 강화**: 사용자간 데이터 격리로 무단 접근 차단
- **프라이버시**: 개인 노트와 템플릿의 프라이버시 보호
- **인증 기반**: Google OAuth 인증 시스템 활용
- **일관성**: 모든 API에 동일한 인증/권한 패턴 적용
- **에러 처리**: 명확한 에러 메시지로 사용자 경험 개선

### Breaking Changes
- ⚠️ 기존 테스트 데이터: userId가 없는 데이터는 조회 불가
- ⚠️ 미인증 요청: 모든 API에서 401 에러 반환
- ⚠️ 타인 데이터 접근: 404 에러로 존재 여부 숨김
